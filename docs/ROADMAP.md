# Roadmap to Install-and-Run Product v1

작성일: 2026-02-25

## 목표
- 각 플랫폼에서 설치 후 즉시 실행되는 제품 후보를 단계적으로 확보한다.
- Transmission 유사 사용자 경험: “설치 후 실행”을 기본 동선으로 정착.

## 운영 원칙
- P0 항목(설치성/보안/기본 안정성) 완료 전 다음 단계 진입을 제한.
- 단계별 검증에서 플랫폼별 스모크 테스트 결과를 반드시 확인.

## 단계 1: 플랫폼 패키징 설계와 기준 설정
### 산출물
- 설치 아티팩트 요구사항 정의서 (MSI/PKG/DMG/DEB/RPM/AppImage/Docker)
- 첫 실행 온보딩 흐름 설계서
- 설치 스크립트 및 자동 체크리스트

### 종료 조건
- REQ-100~104 책임자 지정 및 스펙 동의
- Windows/macOS/Linux 공통 빌드/버저닝 정책 확정
- CI에서 패키지 생성 단계 통과

## 단계 2: 코어 런타임 + 영속성 + mock 정리
### 산출물
- 첫 실행 초기화 완성
- server mock 제거 및 실제 상태 동기화
- 기본 API 스키마/에러 응답 표준

### 종료 조건
- 새 설치 후 상태 조회 API 성공
- 재시작 시 상태 영속성 유지
- REQ-001,010,021,040 중 P0 핵심 통과

## 단계 3: 설치/업데이트/롤백 수평화
### 산출물
- 설치 완료 후 서비스 제어(시작/중지/재시작)
- 자동 업데이트 경로 및 백업·롤백 동작
- Docker 실행 경로 완성

### 종료 조건
- 설치 스모크 테스트(4 플랫폼 동시) 자동화
- 업데이트 실패 시 안전 복귀(rollback) 확인

## 단계 4: 운영성 고도화
### 산출물
- 장애 진단/트러블 가이드
- 리소스/포트/권한 충돌 자동 진단
- 모니터링 메트릭 기본 대시보드 연결

### 종료 조건
- P1 운영성 항목 60% 완수
- 지원 플랫폼 오류 메시지 표준화 완료

## 단계 5: QA/문서/배포 자동화 마무리
### 산출물
- 플랫폼별 설치 시나리오 E2E 패키지
- API 문서/릴리즈 노트 자동 동기화
- 런치 가이드(일반 사용자용) 완성

### 종료 조건
- 설치형 튜토리얼 테스트 통과(신규 사용자가 5분 내 완료)
- 문서-계약 불일치 0건

## 단계 6: v1 후보 공개 준비
### 산출물
- Release Candidate for Install-and-Run
- 운영팀 인수인계 자료(배포/롤백/복구)
- SLA/SLO 모니터링 보드 v1

### 종료 조건
- P0 항목 100% 충족
- 주기 배포에서 자동 업데이트 실연
- Go/No-Go 승인 완료

## 단계별 마일스톤 요약
### 단계 완료 기준 정렬
- 단계 1: 멀티 플랫폼 패키징 설계 완료
- 단계 2: 핵심 런타임 + 영속성 + mock 제거
- 단계 3: 설치/업데이트/롤백 동선 완성
- 단계 4: 운영성/진단 자동화
- 단계 5: 문서·릴리즈 자동화 완료
- 단계 6: 후보 릴리즈
